Manage WooCommerce product pricing in bulk with flexible rule-based automation.

== Description ==

BPMX Pricing Rules for WooCommerce helps WooCommerce store owners manage product prices in bulk using configurable pricing rules.

Instead of manually editing products one by one, you can select the products you want to update and apply pricing changes to them in bulk.

The plugin is designed to make bulk price management simpler, faster, and easier to control.

== Features ==

* Filter WooCommerce products by category.
* Filter products by product type.
* Filter products by stock status.
* Filter products by product status.
* Search products.
* Select individual products for bulk operations.
* Apply configurable pricing rules to selected products.
* Manage product pricing from a dedicated WordPress admin interface.
* Designed specifically for WooCommerce.
* Uses WordPress and WooCommerce APIs for product management.

== Requirements ==

* WordPress 5.2 or later.
* PHP 7.2 or later.
* WooCommerce.

== Installation ==

1. Download and install BPMX Pricing Rules for WooCommerce.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Make sure WooCommerce is installed and active.
4. Open 'BPMX Pricing Rules' from the WordPress admin menu.
5. Use the available filters to find the products you want to manage.
6. Select the products you want to update.
7. Configure your pricing rule.
8. Apply the changes.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. BPMX Pricing Rules for WooCommerce is designed to manage WooCommerce products and requires WooCommerce to be installed and active.

= Is BPMX Pricing Rules for WooCommerce free? =

Yes. BPMX Pricing Rules for WooCommerce is currently available free of charge.

= Can I apply pricing changes to multiple products? =

Yes. The plugin is designed specifically for applying pricing rules to multiple selected WooCommerce products.

= Can I filter products before applying a pricing rule? =

Yes. Products can be filtered using the available product filters before selecting products for a bulk pricing operation.
